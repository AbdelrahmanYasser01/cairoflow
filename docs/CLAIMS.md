# Claims register (2026-11-04)

Every public statement about CairoFlow should map to a row here. Evidence is a committed record,
test or script; "not claimed" rows say what must not be said.
`bash scripts/fresh_clone_check.sh` checks the release rows below on a clone of the committed HEAD.
